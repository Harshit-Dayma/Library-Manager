# 📚 Library Manager

**Library Manager** is a digital interface for managing library operations efficiently. This project provides a modern, responsive UI for three different user roles: **Admin**, **Librarian**, and **Borrower**. It is currently a **frontend-only** project, built using HTML, CSS, and JavaScript. 

---

## 🌟 Features

- 🔐 **Admin Page**
  - Manage librarian and borrower accounts
  - Dashboard for system overview

- 👩‍🏫 **Librarian Page**
  - View and manage books
  - Track issued and returned books

- 👤 **Borrower Page**
  - Browse available books
  - Request/return books (UI only)

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
